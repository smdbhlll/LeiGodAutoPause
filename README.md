# 雷神自动暂停

一个面向 Windows 的轻量雷神加速器时长自动暂停工具。程序使用原生 Go 后台服务和 Win32 桌面窗口，不启动浏览器，不依赖数据库。

> 本项目由 AI（OpenAI Codex）辅助创建：从需求分析、界面设计、代码实现到测试验证均由 AI 完成，人工负责需求确认与发布。

## 功能

- 精确匹配 Windows 进程名，默认每 3 秒读取一次进程快照
- 游戏全部退出后进入宽限倒计时，期间重新启动游戏会取消暂停
- 扫描当前运行进程
- 扫描 Steam 游戏库和 Epic 安装清单
- 扫描结果按分类、进程、路径和来源分列显示
- 支持手动填写任意 `.exe` 进程名
- 原生桌面窗口管理监控列表、倒计时、雷神凭据和手动暂停
- 支持开机自启、开机静默启动和最小化到系统托盘
- 关闭窗口可选择每次询问、隐藏到托盘或直接退出
- 使用专用的雷神自动暂停图标，窗口和系统托盘保持一致
- 使用 Neumorphism 界面：圆角凸起面板、柔和阴影、圆角输入框和带过渡动画的胶囊开关
- 自动跟随 Windows 应用模式切换亮色或暗色主题
- 托盘右键菜单支持“显示窗口”“立即暂停”和“退出”
- 自动查找雷神安装路径，也可在设置中直接选择 `leigod.exe`
- Token 与密码 MD5 摘要使用 Windows DPAPI 加密，只能由当前 Windows 用户解密
- 单文件运行，无第三方运行时依赖

## 使用

1. 运行 `dist\LeiGodAutoPause.exe`，程序窗口会直接打开。
2. 在“游戏监控”中扫描或添加游戏进程。
3. 在“设置”中填写雷神 `account_token`；也可以填写账号和密码，用于 Token 失效时自动刷新。
4. 保持“启用进程监控”和“退出后自动暂停”开启。

点击窗口最小化按钮后，程序会隐藏到系统托盘；单击托盘图标可以恢复窗口。右键托盘图标可选择“显示窗口”“立即暂停”或“退出”，“立即暂停”的结果会通过 Windows 通知显示，不会弹出阻塞窗口。关闭窗口的行为可在设置中选择“每次询问”“隐藏到系统托盘”或“直接退出程序”。“开机静默启动”仅在 Windows 登录时生效，手动运行 EXE 仍会显示窗口。

如果“打开雷神加速器”提示未找到程序，请在设置中点击“自动查找”，或点击“选择程序”定位雷神安装目录中的 `leigod.exe`。选择结果会立即保存。

程序使用 Windows 单实例互斥锁。再次运行程序只会激活已打开的窗口，不会启动第二个后台实例。

配置和日志位于：

```text
%LOCALAPPDATA%\LeiGodAutoPause\
```

## 构建

需要 Go 1.22 或更高版本：

```powershell
.\build.ps1
```

调试时可以把 `build.ps1` 中的 `-H=windowsgui` 临时移除，以便查看控制台日志。
